# 优化工作流(已有老项目)

[English](workflow-checkup.md) | 中文

项目已经在运转、有自己的文件与规矩:第一次引入本包,或已按本包裁过、想检查规矩有没有长歪,都用本件。需要 Python 3.11 或更新版本,命令在拷来的通用包文件夹内运行;项目根指项目放主要文件的文件夹。

## ⓪ 先分两种

- **甲 · 还没用本包的老项目**:第一次接入本包。走 ①②③,再走 ⑤⑥。
- **乙 · 已按本包裁过**:项目根有 `requirements.toml` 或 `裁剪记录.json`,这次是做体检。走 ①②④,再走 ⑤⑥。

两种都先说清:本件缺省**只补缺的**,老项目现有规矩和叫法优先;「全换成本包」只在决策者明说时才做。

## ① 先记原话

把决策者这次的要求逐字追加到项目根的 `资料/决策者原话.md`,带上从当前系统取得的日期与时刻;只追加,不覆盖,不把自己的理解混进原话。盘点前不动任何项目文件。

## ② 只读盘点

只看项目根下的规矩类件:`CLAUDE.md`、`AGENTS.md`,以及名字像宪法 / 规矩 / 章程 / 作业 / 口径 / 记忆 / 接棒 / 工作记录的件;再加决策者点名的件。不翻项目外的目录,不扫代码与素材。本步一字不改,列出「文件 / 字节 / 作用」一张表给决策者看。

## ③ 甲 · 逐句对照通用条目

拿 `entries.md` 逐句对照盘点到的规矩,分四类:

| 类 | 判法 | 去向 |
| --- | --- | --- |
| 已有 | 老项目这句与某通用条说的是一件事 | 记下对应编号,不重写 |
| 老项目独有 | 通用条里没有,是本项目自己的要求 | 进 `本项目自定.md` 候选,每条带原话出处 |
| 冲突 | 与某通用条说法不一 | 列原句 + 通用条编号 + 结果差别 + 推荐,交决策者定 |
| 缺 | 按本项目规模与特征该留、老项目没有 | 列出来,点头后随裁剪补上 |

老项目自己的叫法保留:写进需求卡 `[称呼]`,生成件正文沿用老叫法。照实况填一份 `requirements.toml`(判法照《getting-started.md》③;窗口缺省按需求窗 + 技术主窗两窗起步),裁到 `pending/` 再交决策者看。

## ④ 乙 · 十类毛病逐条体检

对盘点到的每句规矩,按十类找毛病,逐条列「文件:行 / 原句 / 建议(删 / 改成指针 / 二选一 / 留)/ 依据」:

1. 两句打架:同件事两处说法不一,该留哪句交决策者定。
2. 同句两抄:同一句在几个件里各抄一份,留一处,其余改成指到那一处的指针。
3. 过期或旧句没删:已被新决定替代的旧句还留着。
4. 断链:指着不存在的文件、编号或章节。
5. 规矩写进记忆或接棒件:该进规矩件的长期要求写进了临时件,搬回规矩件。
6. 转述扩写:把决策者原话说大了(原话是「这次先问」,写成「以后一律先问」),恢复原话。
7. 自加的闸:四类红线(钱、不可逆、密钥与安全、决策者取向与审美)之外自加的「先问 / 等点头 / 必须先」,列为建议删。
8. 等着已定的事:决策者早已定过、还写成「待定」的,改成已定的说法。
9. 规模变了:项目大小或工作类型变了,改需求卡重裁,列出该加回 / 该拆掉的条目。
10. 窗开多了:没有 G-0222 写的吃力信号,却长期开着三扇以上的窗,建议并回需求窗 + 技术主窗两窗,交决策者定。

你只做搬运、改指针、删重复;规矩该不该有、两句选哪句,交决策者定,每条带推荐。

## ⑤ 一屏报告

照下面模板给决策者一屏报告;说「按推荐」即照推荐执行。

```text
现状一句:……
保留:……
建议补:……
建议删 / 并:……(逐条带文件:行)
冲突待你定:A …… / B ……(各一句影响)+ 推荐 ……
自主假设:……
```

## ⑥ 点头后落地

1. 改前的原件整份挪进项目根 `_旧版/<日期时刻>/`,不删除。
2. 需要重裁的照《getting-started.md》④⑥ 执行:改需求卡,跑 `python3 -X utf8 tools/trim.py validate`,再 `python3 -X utf8 tools/trim.py generate --card requirements.toml --out pending`,生成件放项目根。
3. `CLAUDE.md` 与 `AGENTS.md` 只在末尾追加缺的行,不覆盖原内容。
4. 重跑 `python3 -X utf8 tools/trim.py validate`,确认 0 错。
5. 工作记录写一行:做了什么、怎么回退(从 `_旧版/` 拷回)。

## ⑦ 什么时候再跑

以后项目大小变了(窗口、分工、仓数明显增减),或规矩越写越乱、两句又开始打架时,再跑一次乙;积累了一批新决定时,把新原话补进本项目自定后重裁。

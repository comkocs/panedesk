# 改名待改清单（里程碑一留下的）

里程碑一只把命令行改成 `panedesk` / `pdesk`，并把启动器的帮助文本和诊断前缀改成 `panedesk:`。下面这些按约定**这一轮先不改**，留到发布前统一处理。数字是 2026-10-20 在本仓库里数的。

## 一、包名（npm 作用域）

| 项 | 现状 | 建议改成 | 备注 |
|---|---|---|---|
| 工作区包作用域 | 356 个包用 `@deepseek-ai/*`（`dsh-*`、`cordis*`、`schemastery`、`cosmokit`、`node-addon-system*` 等） | `@panedesk/*` | **发布到 npm 前必须改**：`@deepseek-ai` 作用域属于 DeepSeek，我们发不了；不改的话用户装到的是上游原版包，不是我们的分叉（隐私默认值等改动都不在里面）。 |
| 启动器包 | `@deepseek-ai/dsh`（`apps/cli`） | `panedesk`（无作用域，npm 上已查空） | bin 已是 `panedesk` / `pdesk`。 |
| 根包 | `@deepseek-ai/dsh-root`（private） | `panedesk-monorepo` | 不发布，影响小。 |
| 本轮新建的包 | `@panedesk/slim-base`、`@panedesk/slim-headless`、`@panedesk/full` | 保持 | 已用新作用域，均 `private: true`。 |
| 原生包 | `@deepseek-ai/node-addon-system*`（BSD-3-Clause，`native/system`） | `@panedesk/node-addon-system*` | 各平台二进制要在 Linux / mac 上自己构建发布。 |
| vendor 包 | `@deepseek-ai/cordis` 等（上游已把 Cordis 改名转发） | `@panedesk/cordis` 等 | `vendor/README.md` 记着上游 commit，改名时一起更新。 |
| Python SDK | `deepseek-harness-sdk`、`deepseek-harness-runtime-bin`；模块 `deepseek_harness_runtime` | `panedesk-sdk` 等 | 里程碑一没碰 Python。 |

改包名的配套：`tsconfig.base.json` 的 paths（`scripts/gen-tsconfig-paths.ts` 生成）、各包 `tsconfig.json` 引用、`pnpm-lock.yaml`、所有 `import` 语句、bundle 补丁里的 `name:` 行、`PROFILE_TEMPLATES`、`scripts/` 里的各类校验脚本与发布脚本（`scripts/release/*`）。建议写成一次性脚本整体替换，再全量构建与测试。

## 二、环境变量（`DSH_*`）

源码与补丁里出现约 130 个不同的 `DSH_*` 名字。面向用户、最常用的：

| 变量 | 作用 | 建议 |
|---|---|---|
| `DSH_HOME` | 主目录，缺省 `~/.dsh` | `PANEDESK_HOME`，缺省 `~/.panedesk` |
| `DSH_AGENTS_HOME` | 用户级 agents 目录，缺省 `~/.agents` | 保留 `~/.agents`（跨工具约定），变量改 `PANEDESK_AGENTS_HOME` |
| `DSH_PERMISSION_MODE` | read-only / workspace-write / danger-full-access | `PANEDESK_PERMISSION_MODE` |
| `DSH_TELEMETRY_DISABLED`、`DSH_TELEMETRY_MODE`、`DSH_TELEMETRY_OTLP_URL` | 遥测开关、模式、端点（里程碑一已改为默认 DISABLED） | `PANEDESK_TELEMETRY_*` |
| `DSH_TOOLS_MODE` | native / ptc | `PANEDESK_TOOLS_MODE` |
| `DSH_PRODUCT_ANALYTICS_OTLP_URL`、`DSH_CLIENT_VERSION` 等桌面版变量 | 桌面版 | 随界面里程碑改 |

其余多为测试、快照、CI、发布用（`DSH_SNAPSHOT*`、`DSH_CI_*`、`DSH_GATE_*`、`DSH_COVERAGE_*` 等），可最后批量改。建议过渡期两套名字都认一个版本，旧名打弃用提示。

## 三、目录与文件名

| 项 | 现状 | 建议 |
|---|---|---|
| 主目录 | `~/.dsh`（`packages/util/home-paths` 的 `DSH_HOME_DIR_NAME`） | `~/.panedesk` |

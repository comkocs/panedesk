# 运行中输入框投递

[English](guide.md) | 中文

## 变更

`ui-conversation` 的繁忙态 Enter 偏好保留 `steer` 与 `queue` 两个值。默认的 `steer` 现在等待当前步骤的每个工具完成，再进入仍需执行的下一请求。最终回答先结束本轮，排队输入再开启新轮。`queue` 仍等待整轮结束。待送消息以先进先出的气泡显示在当前回答下方，不再放入输入框的折叠队列。

## 迁移

1. 保留现有设置，无需数据迁移。选择“本轮结束后发送”即可保持轮次边界投递。
2. 使用待送气泡的“立即发送”操作获取旧 Steer 行为。× 操作在 Host 接受后撤回消息，并把文字追加至当前草稿末尾。
3. 在设置界面确认原 `steer` 选项显示为“下一步发送（默认，不打断）”。[持久化确认记录](../../../persistence-changes/2026-11-08-after-tools-input.zh.md)说明可选调度字段；会话格式版本不变。

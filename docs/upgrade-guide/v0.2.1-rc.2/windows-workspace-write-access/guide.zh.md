# Windows 工作区写权限

[English](guide.md) | 中文

## 变更

未选择沙盒模式的 Windows 部署现在使用 `read-only`。Linux 和 macOS 保持 `workspace-write`。显式设置的 `PANEDESK_PERMISSION_MODE`、sandbox-policy 配置或会话模式保留原有含义。基础配置不再在策略解析前插入可写缺省值。

通用设置页为内置本地 Windows 沙盒提供按目录管理的工作区写权限。保存的授权仅在使用平台缺省值时启用工作区写入。已有工作区 ACE 不算已保存的同意记录。首次可能写入的工具调用可请求专用工作区同意；允许后保存目录授权并物化 ACL。拒绝、取消、无应答者及到期均保持工作区只读。无人值守的 `never` 会话不弹提示。

## 迁移

1. 不设置模式即可使用 Windows 只读缺省值。若不再需要之前配置的 `PANEDESK_PERMISSION_MODE=workspace-write`，请删除该覆盖。已有显式会话模式也优先于目录授权。
2. 如需允许某个目录写入，打开通用设置，使用 **Windows 工作区写权限** 选择并授权目录。确认目录出现在列表中，再使用没有显式沙盒模式覆盖的会话。自定义运行器不支持这项设置操作。
3. 检查标为 **旧版授权（无记录）** 的条目。发现范围是本机会话历史与已注册座席目录中的工作区根，不会扫描所有磁盘。撤销前先停止活动的工作区进程。撤销会删除产品沙盒的持久写 ACE 和授权记录，但不会终止运行中的进程或使已打开句柄失效。不要用删除记录代替 ACL 撤销。
4. 撤销失败时，请在设置中重试。持久撤销标记会阻止按目录授权，直到清理成功。显式部署或会话模式仍独立生效；如需只读运行，必须另行移除这些模式覆盖。

当前行为与限制见[策略参考](../../../../packages/sandbox/sandbox-policy/README.zh.md)及[权限设置参考](../../../../packages/client/ui-permission-presets/README.zh.md)。

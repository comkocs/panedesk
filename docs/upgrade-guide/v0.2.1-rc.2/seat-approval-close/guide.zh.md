# 工位审批收窗细因

[English](guide.md) | 中文

## 变更

关闭审批暂停的工位窗口时，现经 Session 控制器取消待决回合，保留排队输入，重新核验停稳证据与授权后才收窗。结束原因仍为 `manual`；引擎收窗记录与 `window-ended` 回调可含 `detail: 'approval-pending-cancelled'`。缺少该字段的旧记录仍可读取，但旧版严格读取器会拒绝含新字段的记录。Session 日志格式与窗口结束原因枚举不变。

## 迁移

1. 升级前停止工位准入，排空在途收窗与回调操作；引擎和所有回调消费方一起升级。
2. 停机时备份引擎账本与各回调消费方的持久域，将备份与旧应用版本配套保留。
3. 更新严格回调读取器以接受可选细因，不为旧记录补造值；下游窗口结束回报保留该细因。
4. 重启新版提供方，关闭工具审批暂停的窗口，确认回合已取消，持久结束记录保留 `manual` 与细因。排队输入及其他忙证据仍须阻止收窗。
5. 不得直接使用含新字段的持久域降级。回退须停止准入，成对恢复升级前持久域与匹配的应用版本；不得删除单条记录的细因。

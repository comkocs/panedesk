# @panedesk/dsh-activity-category

[English](README.md) | 中文

## 概述

对工具执行和模型流归类，不执行验证策略。默认基础装配安装 `activityCategory` 服务，子代理树与父窗输入区展示其任务合计。

## 使用本包

包入口导出 `ACTIVITY_CATEGORIES`、`ACTIVITY_RULES`、`ACTIVITY_REFUSAL`、`classifyActivity`、`activitySummary` 及对应类型。`activityCategory.classify(toolName, args, session)` 解析调用任务确认新建的路径与工作区规则；`activityCategory.read(sessionId)` 返回各类次数、累计毫秒、占比和当前或上一操作。子代理一次激活算一个任务；主窗已提交的人工来源消息开启任务，合成通知不重置任务。新的子代理激活重置自身统计。

`projects` 缺省为空字典，以规范工作区路径为键，值为有序 `{ contains, category }` 行。首个非空文字匹配覆盖默认命令类别。工作区选择器与编辑器位于「Panedesk 特色设置」；值使用既有运行配置，不写用户项目文件。归类规则是显示偏好，不是执行开关。

有序缺省规则区分改文件、读与搜、构建、改动面／全量／变异测试、客户端／端到端、CI 触发、自写脚本、等待和其他调用，模型流单独计时。测试文件、用例与筛选参数归改动面测试；运行模式和仅影响输出的参数不算筛选。成功改文件工具的 `operation: create` 元数据提供脚本证据，既有文件和更新不算。相对执行路径按工具工作目录解析，包括简单 shell `cd` 序列；解释器参数与直接可执行路径和任务确认新建路径比较，包含后代创建的路径。

工具执行接 `tools/execute`，模型计时包裹 `llm/stream`。起止辅助事实复用现有调用账本，使用单调时钟实测时长，不保存模型正文。完成后的合计在进程重启后仍保留。未配对起点仅在服务确认操作仍存活时继续计时，重启不虚构持续执行。次数按操作累加，用时按实测执行时长累加，因此并发操作可超过墙钟用时。脚本标记与主类重叠，不重复加入分母。既有树资源按配置刷新节拍向所有活动视图供数。

`taskIdentity(session)` 提供当前任务及其开工时所属根轮次；`readRootTurn(session)` 合计该轮自身与后代操作。子代理在激活时固定祖先任务号，父窗后来开启新轮次不会重新归属旧工作。任务摘要提供 `verificationMs`，编译、测试、启动客户端、CI 触发和自写脚本按每操作只计一次，脚本标记与主类重叠时不重复累加。

## 模型体验

### 只展示的计量

#### 模型看到什么

不增加提示、工具或拒绝。导出的拒绝模板供独立验证消费者使用，本服务不调用模板。

#### Token 影响

无。计量不发起模型请求，不增加请求正文。

#### KV 缓存影响

无。请求前缀保持不变。

## 已知限制与延期工作

外部登记节点无法归类。藏在新写脚本里的测试挂脚本标记，不推断内部测试套类别。远端 CI 内容未知，只看得到推送或触发。不解释 shell 别名、变量展开、嵌套 shell 和动态脚本路径。后台启动只计工具调用耗时，不计脱离进程的完整运行时长；后续阻塞输出调用归等待。崩溃可留下最终时长未知的操作。计量读写失败会记日志，不阻止工具或模型执行，也不替换其结果；受影响的观测可能缺失。旧账本读取器将这些未知辅助事实报告为不完整，不把它们解释成调用。

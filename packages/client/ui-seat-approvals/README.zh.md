# @panedesk/dsh-client-ui-seat-approvals

[English](README.md) | 中文

## 概要

为[席位子系统](../../../docs/subsystems/seat.zh.md)提供可选启用的审批界面。既有引擎负责准入、授权事务与开窗证据；界面不启动另一个引擎，也不会在已有排队工作旁另发一次开窗。

## 配置与使用

网页组合含名为 `ui-seat-approvals` 的惰性条目。后续档案补丁以 `config: { enabled: true }` 启用；宿主与客户端必须包含同一个包。`enabled` 默认 false，`pollIntervalMs` 默认 1000，`pageSize` 默认 100。正观察间隔限制队列与操作刷新频率；正分页大小限制每次引擎读取。

只有经过认证的所有者远端调用可以读取已启用的待批工作、批准、取消或观察操作。适配器捕获运行节点与待批位及任务归属，取得实例拥有的本地操作员授权，调用既有事务批准或取消能力。它不读取私有端点凭据，也不接受请求字段声明的权限。缺少能力时拒绝，不退回未经审计的变更。

可追加的 `shell.overlay` 条目把待批数量控件放在右上角，不替换已占用的单一顶栏槽位。零待批隐藏数量。对话框显示位、关联单、冻结窗名、经过认证的冻结链目标及保留的预算限额。缺失字段保持未提供；预算以整数微美元显示，包括零。不完整或失败的观察禁止变更。

批准与取消携带观察到的队列版本和新的操作标识。冲突时必须重新检查刷新后的条目。已提交的队列版本在本次挂载中不可再次提交；传输结果未知时保留操作标识供观察，不重放变更。批准仅是确认：容量、策略、时间与预算检查仍然有效。回执跟随持久操作进度；实际开窗卡使用已开结果中的位、标题、节点和预算，不使用待批预览。已创建窗口与首轮完成不同；记录的开窗失败保持可见。

## 模型体验

### 确认与观察

#### 模型可见内容

本插件不提供工具、提示词或会话消息。获批工作仅通过既有引擎执行器到达模型。

#### Token 影响

队列与操作读取不消耗模型 token。获准开窗保留既有模型成本。

#### KV 缓存影响

界面不修改请求前缀，也不刷新缓存。

## 已知限制与后续工作

- 范围是当前运行节点与经过认证的所有者，不覆盖任意委托或远端操作员身份。
- 非链待批项可能缺少经过认证的节点标识。预算缺席表示证据不可用，不表示零或自造配额。
- 观察使用轮询；队列快照可能在分页之间变化，引擎版本比较仍是最终依据。
- 回执选择仅保留于挂载中的界面；关闭它不会取消或重放持久操作。
- 物理开窗、首轮完成与来源回调交付仍是分别可观察的引擎结果。

# @panedesk/dsh-client-ui-trace

[English](README.md) | 中文

## 摘要

「Panedesk 特色设置」页放项目记录的工作区开关。右栏页签列出该工作区的事项、活动、未归属活动和拍板。用户打开之前，记录保持关闭。页签只通过 `traceStore` 远端读写，自己不留记录。

## 使用本包

设置行提供事项记录、关联到已有项目和严格档。严格档只在记录开着时能改，并在本工作区自己的会话里指定一个规划窗。会话标题栏按钮打开 `dsh-resource://trace/session/<sessionId>`，页签类型是 `trace`。记录关着时，页签只显示一句说明和一个打开「Panedesk 特色设置」页的按钮。事项页列出开着和已收尾的事项，可新建事项、看选中事项的时间线、把勾选的未归属活动归进去、收尾，并把选中事项下载为 JSON 或 Markdown。引用按钮读取存下的原文或 diff。拍板页列出现行条目，写明记下它的窗口、模型和时间，并可回退单条。待确认的提议以及确认和驳回按钮只在严格档开着时出现。

## 模型体验

### 项目事项面板

#### 模型看到什么

什么都没有。面板和设置行面向用户。本包不加工具，也不加提示词。

#### 对 token 的影响

打开面板不发模型请求。记录本身也不发。

#### 对 KV 缓存的影响

面板不改变模型输入，也不改变缓存复用。

## 已知限制与暂缓项

- 页签显示屏幕上这个会话所属的工作区。没有工作区的会话只显示关闭说明。
- 导出是在浏览器里下载文件，不写进工作区。
- 时间线用服务的缺省页大小，历史版本按每条现行拍板读取。
- 面板不提供作废事项。

## 开发说明

`src/index.ts` 是空的宿主半侧。`src/client/index.ts` 挂载 `traceStore`，并登记设置行和右栏页签。两侧都只调用这个远端。

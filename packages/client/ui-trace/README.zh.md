# @panedesk/dsh-client-ui-trace

[English](README.md) | 中文

## 摘要

「Panedesk 特色设置」页放项目记录的工作区开关，工作区菜单默认选中主视图会话所在的工作区，没有主视图会话时才取第一个。右栏页签列出该工作区的事项、活动、未归属活动和拍板。用户打开之前，记录保持关闭。页签只通过 `traceStore` 远端读写，自己不留记录。

## 使用本包

设置行提供事项记录、关联到已有项目和严格档。更改成功显示已保存；设置与面板读取或操作失败时显示服务原始错误。严格档只在记录开着时能改，并在本工作区自己的会话里指定一个规划窗。会话标题栏按钮打开 `dsh-resource://trace/session/<sessionId>`，页签类型是 `trace`。记录关着时，页签只显示一句说明和一个打开「Panedesk 特色设置」页的按钮。事项页列出开着和已收尾的事项，可新建事项、看选中事项的时间线、把勾选的未归属活动归进去、收尾，并把选中事项下载为 JSON 或 Markdown。每条活动是一句话，悬停显示记下的类型。未归属活动可以滚动，最新的排在最上面；归入按钮写明目标，没有可归条目时置灰。事项记录开关打开或关闭的回执紧贴开关。活动摘要包含回复或命令开头、改动文件名。每个引用按钮在对应活动下方就地展开或收起折行且可滚动的 diff 行，或保存下来的最多 4000 字回复正文；回复摘要取前 30 字，不含 reasoning。导出保留中文及其他合法文件名字符，立即在导出控件旁显示回执，直到下一次面板操作。桌面端写入完成后显示已导出的文件名，取消则显示取消回执。拍板页跟随已保存的严格档变化，并在拍板写入提交后自动刷新，列出现行条目的窗口、模型和时间，只给尚未回退的条目提供回退按钮。用户确认后，现行条目仍显示原始窗口和模型，不可变审计版本仍记录用户操作。历史中被驳回的提议标为已驳回，无历史时只显示一次空状态说明。待确认的提议以及确认和驳回按钮只在严格档开着时出现；规划窗下拉列表限高且可滚动。

## 模型体验

### 项目事项面板

#### 模型看到什么

什么都没有。面板和设置行面向用户。本包不加工具，也不加提示词。

#### 对 token 的影响

打开面板不发模型请求。记录本身也不发。

#### 对 KV 缓存的影响

面板不改变模型输入，也不改变缓存复用。

## 已知限制与暂缓项

- 页签显示屏幕上这个会话所属的工作区。没有工作区的会话只显示关闭说明。
- 普通 Web 发起浏览器下载后保留正在导出的回执，因为浏览器不提供完成或取消结果。桌面端使用归属的保存框，只写入用户选择的位置。
- 时间线用服务的缺省页大小。现行拍板和历史共用一份实时版本列表。
- 面板不提供作废事项。

## 开发说明

`src/index.ts` 是空的宿主半侧。`src/client/index.ts` 挂载 `traceStore`，并登记设置行和右栏页签。两侧都只调用这个远端。

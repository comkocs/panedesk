# 数据库连接设置

通过统一设置槽位、类型化中英文文案和生成的 `databaseConnections` Remote 贡献，增加 **设置 → Panedesk → 数据库连接**。

## 使用方式

添加、修改或删除具名 PostgreSQL 连接。粘贴连接串即可自动拆出主机、端口、用户名、密码和库名，也可直接分项填写。页面显示缺省值，密码遮蔽，URL 解析成功后清空原串。修改时秘密字段留空保留原值，明确勾选清除才删除。测试使用未保存表单，以白话结果和原样单行错误回报。

SSL 验证数据库证书。SSH 使用宿主私钥路径，可从目录和文件浏览器选择；浏览器只收到名称与路径，不接收私钥内容。开启隧道时数据库主机从 SSH 服务器访问。配置区域显示 JSON 绝对路径，打开按钮沿用宿主路径操作。每个连接的模型访问开关缺省关闭，页面明确说明 SQL 受数据库账号权限控制，包括写入。

## 模型体验

页面自身不增加模型上下文。开启模型访问会更新 SQL 工具的连接名选项；密码、SSH 口令和私钥内容不会成为工具参数。

## 已知限制与后续工作

此页配置用户数据库访问，不切换 Panedesk 自身存储后端。打开文件依赖宿主桌面集成，远程或无桌面宿主可能拒绝，页面仍保留路径。私钥选择器浏览宿主文件系统，不是浏览器机器。离开页面会丢弃本地草稿，且不提供秘密回读。

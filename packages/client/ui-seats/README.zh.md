# @panedesk/dsh-client-ui-seats

[English](README.md) | 中文

## 概述

为新会话页芯片、左栏工位节与实例会话头身份提供可选[工位](../../../docs/subsystems/seat.zh.md)界面。Web 组合默认禁用本插件，须显式启用；不内置内部位名。

## 使用本包

已认证所有者通过 `seatUi` 读取档案及在开会话状态。手动开窗调用现有工位提供方，指定 `openingMode: 'prefill'`，保留其目录、预设、模型与权限配置阶段，不启动模型回合。返回的开窗句初始化草稿，等待用户提交。提供方缺席时隐藏芯片与左栏节；证据不完整时禁用开窗。

每个位行提供“新会话、工位档案、在工单台看本位、一览表”。节头一览入口仅在指针悬停或键盘聚焦时出现，不占冷启动首屏。一览表位于中栏，显示位名、节点、在开否、模型、真实最近开窗时刻及待批数；显式勾选后以人工预填调用 `seat.openBatch`，不带任务号，各位拒绝保持可见。档案与私有工单台导航要求各自提供方另行装配。

批量开窗超时或断连后，禁止继续提交，直到显式刷新返回新的存活观察。客户端在结果未知期间保留批次操作身份，重试重放宿主原操作，不重复创建窗口。

工具审批未决时，位行显示“待审批”。展开的会话行提供所有者授权收窗，携带所显示的状态版本；工位提供方先取消暂停回合，再收窗，其他忙因仍拒绝。收窗结果刷新同一资源，拒绝使用现有 Toast。

档案可用但为空时仍显示“工位”标题、空态与“添加工位”操作。将 Host 的 `home` 配置为产品家目录绝对路径以启用源件准备。添加只填工位名、已存在的绝对工作目录、已配置模型和开场句；模型来自现有 Session 模型目录。仅所有者可调用的 `seatUi.prepareAdd` 在家目录内原子发布私有 CSV 快照，保留已有定义并追加一行。Client 调用现有 `seats/import.preview` 和 `seats/import.commit`，要求恰好一条无诊断的 create 行，确认后仅提交该行。添加不打开窗口、不发送模型请求。目录、重名、模型及导入失败均有本地化恢复提示；提交结果不确定时须先刷新再重试。

两个开窗入口在目录不同时均提供档案目录、仍在此开、取消三选一。仍在此开仅为本次开窗请求精确的已登记目录；未登记目录会被拒绝，显示原因并提示改到档案目录，不扩大权限，也不改档案。芯片由所有者传入 Session 当前工作目录投影，尚无 Session 时传入待选工作区。左栏从唯一由主视图保留的会话读取同一投影，多个主视图使当前目录有歧义时禁用开窗。

业务数据走客户端资源，由 Session 生命周期通知、引擎诊断失效通知、连接重置及本地开窗结果刷新。最后一个持有者释放或插件卸载会取消在途概览读取并移除刷新监听。头标识读取精确的 Session 绑定元数据，与档案及在线故障隔离。已核的工位和节点或自由窗身份保持可见，异常另标；证据缺失或被拒时明确显示读取中或读取失败，不猜自由窗，也不借用其他会话绑定。左栏展开已有会话并显示现有工位状态，不新增忙闲接口。拒绝使用共享 Toast 原子组件显示，包括经 Session 资源鉴权、仅在匹配会话显示的记忆拒绝事件。

展开的左栏是本地化引擎、停车回调、未创建开窗及活窗模型告警的唯一落点，支持换行并限制可滚动高度。折叠的左栏仅在存在诊断时显示告警图标；点击后展开左栏，查看完整告警，即使档案为空也可查看。没有诊断时不增加折叠入口。冷启动选位器与头部不重复这些告警。冻结人工开窗或来源唤醒的孤窗收窗提交后，在此显示一条本地化告警，标明原入口并提示重新开窗或唤醒。告警跨重启保留，直到同一工位后续成功开窗；告警本身不发起开窗。缺预设诊断给出冻结的预设名与拒绝码；恢复预设并成功打开该工位后清除告警，失败意图仍保留审计。可重试引擎告警仅在完整恢复轮次成功后清除；已停止的引擎要求修复并重启宿主。连续不可用超过十分钟时，同一区域增加本地化告警，提示所有者查看宿主日志；引擎恢复 running 时清除。签发器拒权的停车告警标识回调与工位，提示恢复原账号后恢复或放弃回调，退出停车态后清除；引擎与独立回调链继续运行。失效通知不携带诊断正文，每次概览读取仍要求所有者权限。没有会话头时，冷启动选位器也显示开窗拒绝。模型不可用告警给出工位、提供方和模型，说明其他工位继续运行，并提示恢复模型后在原会话重发；模型配置成功后清除开窗告警，不重放原开场。活窗回合告警在重发回合成功完成或对应运行时释放后清除，不改变回合错误分类。

开窗定义无效告警写明工位，说明仅该工位开窗失败，提示修好定义后重开；定义修改或该工位成功开窗后清除。回合准入告警则说明已有窗口停车、输入尚未认领，提示修复配置，准入确认修复后保留输入可继续处理；准入确认修复或该运行时关闭后清除。回调认证告警写明工位和回调，说明无效果停车等待人工，提示修复认证后恢复或放弃。独立工作继续，退出停车态后清除回调告警；效果未知或非零时仍显示引擎停止告警。

<a id="dev-note"></a>

## 开发备注

席位提供方拥有开窗策略与 Session 身份；客户端资源拥有观测刷新与取消。两个开窗入口共享包内的目录确认组件。发布的运行时入口使用已打包的 Host 与 Client 文件；纯类型入口只发布声明，不包含未打包的 Client 模块。

<a id="model-experience"></a>

## 模型体验

### 手动选位

#### 模型看到什么

以 `openingMode: 'prefill'` 选位不产生模型请求。开窗草稿仅在用户提交后对模型可见；拒写保留带码工具结果。

#### Token 影响

芯片、左栏、身份与吐司内容不增加模型 token。已提交的开窗句与工具拒因按正常输入及结果计入 token。

#### KV Cache 影响

界面选位与瞬态通知不改变已有模型前缀。

<a id="known-limitations-and-deferred-work"></a>

## 已知限制与延后工作

- 仍在此开仅支持精确的已登记工位目录，不能授予新目录。
- 实例身份标识位于前导区域中的独立 `conversation.header.seat` 槽；既有根作用域 leading 槽没有 Session 身份，保持不变。
- 已有会话冲突需从左栏选窗；此包不实现换窗与独立回合取消。关闭审批暂停窗口时，由工位提供方执行取消。
- 不伴随 Session 通知的档案变化需重新打开资源后刷新；不引入轮询间隔或平行档案缓存。

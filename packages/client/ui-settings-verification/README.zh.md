# @panedesk/dsh-client-ui-settings-verification

[English](README.md) | 中文

## 概述

在 Web／桌面共用装配加入「设置 → Panedesk → 验证」。设置外壳提供三句共用页头。页面选择工作区、读取验证策略，并通过所有者专用远端保存完整带版本号记录。工作区菜单默认选中主视图会话所在的工作区，没有主视图会话时才取第一个。

## 使用本包

可选「缺省」「不限（只统计）」「只编译」或「自定」。控件包含启用、全量允许／只一次／禁止、变异测试、自写脚本、CI 触发、改动面测试、客户端等待分钟及任务验证分钟或占比预算。数值留空表示不限。保存影响后续调用策略，不改项目文件或模型可编辑设置。子代理树通过 `settingsNavigation.openSection('verification')` 打开本页。

服务拥有预设值与裁决逻辑。页面显示读取／保存失败及服务原始错误，保存成功前编辑仅在本地。保存成功后使用返回的设置并显示「已保存。」，不重新打开资源；重开页面时读取持久化设置。关闭验证后统计继续。页面明确显示预算审批限制与归类盲区。

## 模型体验

### 工作区策略编辑

#### 模型看到什么

本页不增加工具或模型消息，由配套 verification-policy 服务告知并约束模型。

#### Token 影响

本界面包没有影响，不发起模型调用。

#### KV 缓存影响

没有直接影响；保存策略会改变配套服务的提示行。

## 已知限制与延期工作

现有审批框仅支持单次许可或拒绝，不支持提示中列出的任务级选项。包编译不代表已启动客户端或通过行为测试。

## 开发备注

显式声明客户端服务依赖，线上数据使用服务的浏览器安全类型入口。

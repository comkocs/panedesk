## 概述

在[网页客户端](../../../docs/subsystems/web-client.zh.md)的“设置”中增加二级“节点”节。[宿主管理提供方](../../host/host-admin/README.zh.md)负责节点观察与既有操作员执行；本插件仅提供经过所有者认证的读取与确认后的本机操作。

设置操作使用共用的有边框按钮，确认使用主要操作样式。

## 配置与使用

网页组合一同加载宿主端与客户端，`enabled: false`。页面说明多机用途，提供当前配置档全局开关，接到已配置 node-link 条目的 `enabled` 字段，其缺省也为 false。关闭通过 Loader 正常生命周期排空传输并停止浏览器轮询；手动读取与配置入口仍可用。启用前须配置恰好一个 node-link `runtime`；页面不安装引擎、不生成凭据。`refreshIntervalMs` 默认为 10000，接受 1000 至 2147483647 的整数，输入框失焦时通过配置档编辑器保存。它仅控制观察刷新，不改变传输心跳与回调重试。`pageSize` 默认为 200，接受 1 至 200 的整数。缺失的提供方保持不可用。卸载时取消轮询并封闭新操作，再等待已受理操作结束。

Panedesk 共用页头说明缺省单机用法。多机控件、观察与动作收进页底的**高级(单机用不着)**，不改变原有行为。

页面显示宿主配置档补丁的绝对文件路径与目录，复用桌面打开文件和显示所在目录动作。标准位置为 `$PANEDESK_HOME/profiles/<profile>/cordis.patch.yml`；node-link 对端参数和 seat-engine 回调参数共用此文件。设置作用于该宿主配置档的所有工作区，而非选中的项目。凭据文件和回调日志仍位于各自配置的私有存储，本页不读取其内容。

此节使用共享节点图标，不贡献首屏、侧栏或主区域入口。节点行显示本机身份、引擎和链路观察、未知容量、最近一次认证往返成功时刻，以及可展开的自本次启动的进程内事件。单独重拉只替换本宿主到所选对端的隧道；其他节点的出站链路须在该节点操作。新子进程不代表认证链路已经恢复。

停车回调行使用实时发件箱观察，保留预期尝试次数。来源提供方行保留原操作员键。恢复和放弃均须二次确认操作名称与目标；所有写入复用既有本地操作员授权。提供方拒绝、未知结果与接受操作明确区分。结果未知时须先查询再重试；插件不自动重复写入。默认、加载、空、读取错误、无权限、禁用、成功及操作失败均有中英文案。

<a id="model-experience"></a>
## 模型体验

### 节点管理

#### 模型可见内容

`settings.section` 贡献不注册工具、提示词或会话消息。观察与确认只对用户可见。

#### 词元影响

读取和隧道重拉不派发模型请求。恢复既有工作仍沿用该工作的正常执行及词元政策；页面本身不调用模型。

#### KV 缓存影响

插件不改变模型请求前缀或缓存。

## 已知限制与待完成项

<a id="known-limitations-and-deferred-work"></a>

- 事件不持久化，每对端仅保留自本次启动最近 20 条。心跳为观察时刻，不是引擎就绪时间。
- 回调列表有界并标明不完整；来源提供方页没有完整性证明，空结果不代表所有工作已清空。
- 缺失的历史尝试时刻保持未知。恢复后的重试下界显示“至少 N”；来源适配器不拿创建或恢复时刻编造尝试时刻。停车回调行把失败次数与直接 pending 派发分开显示，各自带首末时刻。分项前写入的摘要对两组都显示“未记录”，且不从合计次数推算。
- 页面不能重拉远程节点自身的出站链路、修复凭据或撤销放弃。操作被接受后仍须重新读取以检查结果。

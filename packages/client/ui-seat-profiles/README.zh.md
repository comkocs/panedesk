# @panedesk/dsh-client-ui-seat-profiles

[English](README.md) | 中文

## 摘要

此可选插件在设置中增加“工位档案”，不新增冷启动侧栏入口。已认证所有者可查看、编辑本机[工位](../../../../docs/subsystems/seat.md)目录，确认删除定义，并预览映射后的 Markdown 或 CSV 源文件勾选行。

## 使用本包

同时启用插件两面，并配置本地工位提供方、设置外壳、资源、语言和 Remote 服务。位行通过 `seatProfilesNavigation` 打开此分区；分区撤销时相应导航服务一并移除。Client 配置可传入 `presets`，每项包含 `id`、已本地化的 `label` 和 `columnMap`；产品专属表头放在产品配置中，不进入通用解析器。

选择工位后暂存编辑。可改工作区、记忆目录、开窗文本或文件、章程 / 开窗必读件、Agent 预设、提供商、模型、推理档位、权限预设、平台与节点；开窗规则和其他限制放在折叠区域。结构字段使用 JSON，位身份、格式版本和导入元数据保持不变。保存递增定义版本并提交观察到的目录版本；冲突保留草稿，显式刷新才丢弃草稿并重读。保存成功后更新本地编辑版本，供下次保存使用。

来源持有的目录须由所有者单独确认，将整个目录转为本地编辑。此操作沿用既有授权留痕；保存与删除不会暗中转交。删除前列出在开窗口与待批，确认后仅移除定义，不关闭窗口、不取消审批。既有工作若仍依赖该定义，后续操作可能以 `seat-not-found` 拒绝；删除前须核对该影响。

导入读取宿主源文件路径。选择 Markdown 或 CSV，可指定 Markdown 表格标题，填写 JSON 表头到字段映射及完整定义默认值后预览。不自动勾选任何行；无效、冲突和未变化行不能勾选，逐行诊断与本地 / 来源差异保持可见。提交沿用既有 preview/commit，仅提交勾选行号。修改源、映射或默认值会清空预览。可用当前档案填充默认值，但来源身份仍须显式映射。映射转换、来源新鲜度及 CAS 行为见[本地提供方](../../seat/seat-local/README.zh.md)。

## 开发说明

Host 适配器访问 `seatProfilesLocal` 前核验存活的所有者调用。组件只接收框架资源 / store 属性和普通回调。工位选择由设置分区 store 持有，暂存编辑与导入勾选由各挂载组件持有。

## 模型体验

### 档案维护

#### 模型看到什么

编辑、删除与导入定义不会发送模型请求。后续开窗由既有工位开窗流程使用已受理的 `opening` 和 `openingInstructionFiles` 值，不改写既有 Session 消息。

#### Token 影响

表单、预览和回执不增加模型 token；开窗指令仅在实际提交开窗输入时消耗正常输入 token。

#### KV Cache 影响

档案维护不替换既有 Session 前缀，也不使活跃模型缓存失效。

## 已知限制与延后工作

- JSON 字段要求完整有效结构；本编辑器不提供目录选择器或自然语言模型解析。
- 定义删除与引擎活动使用不同存储事务。确认会在目录变更前核对影响和引擎序列，但不会在整个目录持久化期间锁住后续引擎活动。
- 资源撤销会取消 Remote 观察并移除失效监听，但不会撤销已经受理的目录写入。
- 宿主源文件须预先存在且可读。浏览器不上传文件，也不猜测缺失的模型、节点、预设或权限默认值。

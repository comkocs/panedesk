# 数据存储设置

新增**设置 → Panedesk → 数据存储**，提供本机（缺省）和已存连接名选项、仅执行 `SELECT 1` 的测试连接，以及可选本机数据复制。连接在『数据库连接』页添加。页面显示配置文件绝对路径与打开/定位按钮、当前后端、连接错误和重启提示。[后端说明](../../storage/storage-postgres/README.zh.md)统一说明持久化、迁移和凭据行为。

## 模型体验

不新增模型工具、提示词，不改变 token 消耗或 KV 缓存。页面只调用经过所有者认证的设置方法。

## 已知限制与待办

修改重启后生效。首次打开配置文件前需先保存。页面只处理连接 id 和名称，不处理凭据。打开本机路径依赖主机已有的桌面路径打开能力。

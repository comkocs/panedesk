<a id="behavior"></a>
## 行为

会话浮层等待当前欢迎提示已确认、主会话就绪且不再为空白，再按工作区路径询问一次关、只提醒或自动；只提醒是初始草稿，不代表隐式批准。成功选择保存在产品档案的 `ui-project-onboarding.projects` 字典中，不写用户项目。项目开窗设置页列出已有工作区和已存目录，无需进入项目会话。页面解释各档行为和只提醒缺省档，点击档位即保存。页面展示产品配置和 JSON 工位档案的文件与目录绝对路径，提供宿主原生打开和定位动作，并可显式刷新引擎的在跑、恢复中或不可用状态。工位档案包含本机所有项目；本地服务缺席或使用非 JSON 后端时没有可打开的本地档案文件。项目级可调偏好只有开窗档位，引擎部署参数仍由宿主管理。只读设置禁用写入；失败保留先前可见选择并提供重试。

Panedesk 共用页头提供三步初次使用说明，并明确档位修改只能手动。产品偏好保持可见，引擎观察和工位目录收进**高级(单机用不着)**。

仅所有者可用的 `projectOpening.select` 从完整且已授权的本地席目录解析匹配项目，以修订号检查应用引擎策略，再持久化产品偏好。保存失败后，以本次保存拥有的修订逐项尝试恢复，包含原 `modeChosen` 标志。不会覆盖并发赢家；若并发恢复已经与原字段一致，则计为已恢复。结构化结果与本地化反馈逐项报告已恢复、冲突或失败后结果不明。

没有匹配席时仅存偏好，不启动引擎。由插件生命周期拥有的同步解析器，在引擎首个准入事务内读取工作区已存选择，覆盖新导入席。策略与准入或禁用拒绝一起提交，不靠事后通知修补首个决策。项目显式策略优先；同一席的多个目录若有互相冲突的已存选择，则拒绝准入，不任意选一个目录。卸载插件只移除解析器，不删除已经提交的策略。

工作模式包动作将新项目的 `/workflow-pack` 请求插入当前输入框并保存草稿，不发送消息、不写项目文件。新会话首屏在品牌标与输入框之间提供新项目、有产品文档、已有项目三个可选入口。点击后填入草稿并聚焦输入框；有产品文档的入口选中文档路径占位。用户打字或发送后入口收起，有消息的会话不显示。Panedesk 特色设置中的 `ui-project-onboarding.showWorkflowStarters` 控制入口显示，缺省为 `true`。

<a id="dev-note"></a>
## 开发备注

宿主偏好与席策略同步位于 `src/index.ts` 和 `src/opening.ts`；客户端入口位于 `src/client/`。客户端读取与失效刷新使用共享设置描述镜像；成功选择的回复折回该镜像，不另发描述请求。

<a id="model-experience"></a>
## 模型体验

### 项目引导

#### 模型看到的内容

查看或保存 `ui-project-onboarding.projects` 偏好不增加模型上下文。工作模式包动作在用户发送前只修改可见草稿。

#### 令牌影响

查看或保存偏好不发模型请求、不消耗模型令牌。自动档可能允许后续规则驱动的模型工作。

#### KV 缓存影响

用户发送草稿前，本包不改变提示前缀或保留的模型历史。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 工作区键是宿主目录路径；别名和符号链接不合并。共享同一精确目录的席项目接受相同的明确选择。
- 产品持久化和引擎日志是独立存储。报告回退冲突时需人工审查策略；不承诺跨存储原子性。

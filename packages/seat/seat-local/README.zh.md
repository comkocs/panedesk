# @panedesk/dsh-seat-local

[English](README.md) | 中文

## 概述

此可选提供者使用私有档案存储、经认证的操作作用域和已安装的工位引擎实现[工位服务](../seat/src/index.ts)。它不会启动客户端，也不会隐式选择节点。缺少引擎或运行时证据时返回明确的不可用结果，不会声称没有窗口或窗口空闲。

<a id="configuration-and-ownership"></a>
## 配置与归属

函数插件导出 `apply`、`inject` 和配置类型。配置 `LocalSeatOptions`：档案目录、节点身份及别名、已解析的定义默认值、正数输入与事务限制，以及关闭标题后缀。`storageDomain` 为必需项；引擎和会话能力通过可选服务查询接入。受控开窗需要公开会话创建、代理、账本、标题、权限及订阅提供者。

存储布局：配置的档案目录保留专用 `catalog.lock`，与档案及导入计划文档分离。Linux 与 macOS 保持原描述符 flock 和争用即失败语义。仅 win32 使用独占共享打开，在最多 100 毫秒内以 10–40 毫秒退避重试。锁文件内容从不读写；关闭句柄或进程退出即释放所有权。可能存在所有者时不得删除或替换锁文件。

档案最初由导入源管理。记录权威变更后才允许直接编辑档案。导入预览在档案写锁下持久保存到版本 1 的 `seat_import_plans` 单文档存储域，不改变档案修订号；跨进程提交时重新核对源摘要及修订号。计划默认 24 小时过期，可配置 `importPlanTtlMs`；过期返回 `import-preview-stale`，下次预览回收其占用的 `maxPlans` 容量。档案路径在任何宿主上均接受 POSIX 绝对路径及完整的 Windows 盘符或 UNC 路径；目录比较采用路径自身的语法，Windows 路径忽略大小写。实时操作先拒绝跨节点，再以 `invalid-definition` 拒绝不兼容的执行路径并提示修改档案；导入来源元数据不属于执行路径。异平台根目录不拥有本机目录，不兼容的档案不暴露可用目录根。实时操作要求可信适配器提供 `withAuthority`，并拒绝跨节点请求。目录授权结合已保存的工位路径与当前文件系统及沙箱策略；列入档案不能绕过沙箱拒绝。

可选 `remoteAdmission` 保留显式来源节点、来源、主体及冻结方法许可列表与正整数政策修订号。列表必须非空、无重复且无通配，`allowOpen` 必须为真。省略时不添加默认字段，也不授予远端权限。档案解析本身不启用远端执行，也不放宽本地节点解析。`openFrozen` 和 `wakeFrozen` 的无窗分支接受经认证的冻结正文，不解析其提供方，也不再次路由。引擎将原 wire 摘要、完整业务键与派生本地意图同次提交；重试先于新受理检查返回首次排队受理结果，即使远端许可已撤除。完整进程重启后的查询恢复相同回执；不完整日志帧不产生部分受理。可选业务注册等待本地恢复，就绪前报告未知。带授权的有窗唤醒仍不可用。显式 `nodeWorkChain` 装配在政策及本地恢复屏障就绪后额外启用节点批量。全批在写入前检查；各成员随后独立提交，绑定原批授权与确定性本地操作。重试返回原排队回执并继续缺失成员。携任务的授权若无 wire 改面证据，在任何成员提交前拒绝。

上下文开窗与唤醒在本地解析前查询引擎可选的[来源代理](../seat-engine/README.zh.md#use-this-package)。远请求保留完整原上下文和入口凭证；冻结准备与逐次 wire 授权归注入组合。结果未知时保留来源占位，不回退本地开窗。未装配时，既有本地准入和远端拒绝保持不变。

<a id="window-transactions"></a>
## 窗口事务

`seatOpeningContexts.registerScopeAdmission` 可选安装一个可信所有者，串行化来源开窗和批次受理。其评估器只替代任务改面检查，既有开窗策略仍执行。所有者在执行前保留持久占位，注销时排空在途操作。其可选 `recheck` 在排队派发和恢复未完成开窗前再次确认冻结许可，不进入正在等待引擎的受理串行链；必需策略缺席或正在注销时保留占位，不放行执行。未注册时，任务批次保持原评估器查询及缺席时的 `scope-unknown` 拒绝；只带席位的调用不变。

`registerSourceOwner` 安装唯一受信所有者，转发准备、准入复核和回调投递。没有所有者时不暴露这三个方法。注销立即移除方法，拒绝已捕获的旧调用，并在允许新所有者注册前排空已接纳调用。

模型工具开窗捕获存活会话及调用标识，通过可选引擎签发器签发 `model-tool-call` 归属，并与触发接纳同次提交。请求字段不能选择授权种类。签发器缺席时保留原开窗行为。

`seatOpeningContexts` 接纳受信进程内提供方。手工与已注册引擎入口冻结同一版本正文，不作模板展开；已接纳的重试即使在提供方移除后仍复用持久快照。引用不授予权限。提供方可选回调通过引擎持久发件箱接收手动开窗结果，携带冻结引用及原操作身份。会话创建记录 `opened`；自动首轮失败另记 `opening-failed`，预填不启动回合。提供方缺席时保留待重投。无引用的手动开窗保留空回调；切换或唤醒已有窗不产生新的 `opened` 回调。可选 `seatOpeningContexts.wake` 仅在无窗转开窗时使用引用，走同一开窗准入。注销拒绝新解析和投递，并排空在途操作。任务批次在任何成员开窗前要求已安装的改面评估器及完整证据；拒绝给出串行替代。未使用这些增量的旧请求保留原路径。

传统创建在工厂执行前核对目录归属；不匹配或多候选时返回候选与开位命令，不自动选位。可信适配器通过 `seatLocalCreation.confirmTraditional/run` 消费一次性传统确认；自由身份旁存于引擎账本，不写入 Session 头、不进入位名册。父窗身份来自持久开窗或绑定事实。自由创建注册失败清理，因此未经确认的工厂创建失败也会在返回前释放临时账本归属。恢复在驻留计账前核准入：持久席位绑定提供归属，自由或无绑定恢复保留循环既有的启动标签解析。临时恢复绑定在工厂结束后释放，成功驻留归属由循环持有。两条路径均不改 Session 头。

本地单开在首次接纳前调用可选 `before-open`，批量在首位前调用 `before-batch-open`；直接引擎开窗通过注册的 `preAdmit` 在接纳及会话副作用前调用同一策略，拒绝只按既有方式记录一次策略审计。已接纳操作按冻结输入重放。人工续查同时核对运行时忙与缓存证据。列窗独立展示运行时六态和引擎预算停、closing，二者均不可续。

策略宿主用现有存储域持久保存工作树登记及操作身份，以只读 Git 查询验证仓库与分支；`repositoryId` 是 Git common 目录的规范路径。提醒通过既有持久消息投递走 steer，不把接纳当作模型完成。收窗提醒在串行投递前持久保存原文及操作身份；恢复复用两者进行持久投递去重，已标记发送的记录不再重发。版本 1 的 `seat_close_reminders` 存储域采用 `per-record` 布局：`reminders` 表以操作身份摘要为键，保存字符串字段 `sessionId`、`operationId`、`text` 及布尔字段 `sent`。这些记录独立于 Session 历史。

人工开窗将定义、日期标题、渲染文本及请求冻结到持久入口。窗名与模板变量 `date` 按节点配置时区取当地日期，缺省 UTC；`date` 保持 `YYYY-MM-DD` 格式。预填在配置完成后返回冻结草稿，不发送输入，也不启动回合。提供者私下注册引擎专用的可信列窗和收窗能力；公开的无作用域服务仍拒绝未携带权限的调用。执行器使用已预留的会话身份，在创建或恢复期间绑定账本归属、配置窗口，并经持久消息投递发送开场。换窗完成要求原始开场消息、包含它的已完成回合以及助手回复；后续无关回复不符合条件。

执行器仅从执行会话最近的 `request/header` 或 `model/selection` 记录读取模型证据。日志缺失或不可读时返回明确缺失，不读取配置模型，也不激活会话。引擎将此证据与路由回调一起冻结。

已认证的 `operation` 优先读取可选引擎操作投影，包括批准登记及关联开窗进度。能力缺失或未找到操作事实时保留原本地效果查询；查询不启动引擎，也不执行动作。

原始开场消息所在回合若有持久化错误终态，即使投递回执仍为 injected，也将开窗判为失败；中断或仍在运行的回合不视为提供方失败。

已认证收窗仅在引擎已记录原持有者死亡且资源释放并隔离后，才可通过 Session 控制器恢复持久窗口，以取得会话所有权并检查当前忙证据。恢复不会重建已隔离的引擎资源，也不授权新模型回合。会话水位变化时须重新列窗并提交收窗请求；所有权未知或仍有待办仍阻止归档。

人工续期使用引擎维护路径。收窗阻止新回合、重新检查证据、归档会话、固定关闭标题，并在记录终态账务之前刷新持久化。归档前失败会解除屏障；归档后失败会保留屏障以便重放。改名收据保留原始结果，因此重放早期改名不会覆盖后续标题。中间标题历史不明确时拒绝操作，不会报告成功。

等待保留已授权对象身份和终态观察。任务读取定向访问所属会话，不扫描全部会话。调度投递只有在消费它的模型回合完成后才算完成；删除表示取消，不表示完成。提供者卸载时排空已接纳的观察工作，重新加载时从引擎事实恢复未完成等待。

受控创建与恢复会在发布 agent 前，可选地从 `hostSessionCredentials` 获取会话绑定凭据。shell 环境注册表仅为调用会话提供 `DSH_HOST_ENDPOINT_PATH` 与 `DSH_HOST_CREDENTIAL_PATH`，不提供凭据值。归档、替换与 agent 释放会撤销旧绑定。缺少管理签发器时，创建行为不变。当前持久位绑定没有员工字段，因此本提供者仅签发位身份，绝不猜测员工号。

<a id="model-experience"></a>
## 模型体验

### 开场与唤醒消息

#### 模型看到什么

模型收到配置工位定义中的开场或唤醒渲染文本。模板在接纳前解析工位、日期及可选单号；重放复用保留的开场文本。窗名与模板变量 `date` 按节点配置时区取当地日期，缺省 UTC。订阅内容由已安装的指令订阅提供者提供。

#### 令牌影响

渲染文本和订阅指令进入模型请求时消耗输入令牌。档案读取、资源预留及操作收据本身不调用模型。

#### KV 缓存影响

开窗创建新的会话历史。唤醒向现有历史追加输入。订阅变更遵循订阅提供者的请求前缀行为；本提供者不改写既有模型可见消息。

### 上下文、预算与等待提醒

#### 模型看到什么

窗口上下文提醒为 `Context threshold reached. Consider replacing this window after reporting its pending work.`。子窗上下文提醒为 `The child context reached its limit. Prepare a handoff summary for a new subagent.`。两者均使用 steer 投递。预算提醒携带引擎预算快照；等待消息标明各对象及观察到的结果。

#### 令牌影响

提醒在下一个获准回合中消耗输入令牌。上下文估算使用最近已完成普通对话调用的输入、缓存读取和缓存写入令牌数；缺少证据时为未知。成功持久化的压缩只有在后续普通调用提供用量后才开启新的提醒周期。

#### KV 缓存影响

提醒追加输入，不取消当前步骤，也不替换既有历史。稳定操作身份抑制同一定义修订和压缩周期内的重复投递。压缩本身由已安装的压缩提供者负责。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与待办

- 续期、换窗和关闭将签发凭证传入原日志准入。存活模型调用为这些动作签发 `model-tool-call` 凭证，引擎专用关闭签发 `engine` 凭证。关闭在归档前复核权限；带审计凭证重试已有屏障时要求本地对账，不重放外部工作。未携凭证的旧调用保留原路径。
- 提供方为开窗、续期、换窗和关闭安装 `nodeAuthorizedLocalAdmission`。带审计凭证的改名和唤醒仍不可用；未显式装配新链时，节点批量保持不支持的拒绝。扩展上下文开窗与任务批量仍缺远端 wire 证据。CLI 权限尚未接线。
- 工作树成熟度需要显式上游、经核验的合并祖先关系，以及提交、Git 元数据和已跟踪文件的活动时间。证据缺失，或检查期间 HEAD、上游或已跟踪工作树发生变化时，不判定成熟；强制登记仍需独立授权。
- 引擎不暴露可选开窗事务时，持久预填接纳不可用。本地入口会拒绝它，而不是意外发送首轮。
- 恢复的会话缺少暂存收据对应标题事件时，改名恢复会拒绝操作，不推断结果，也不猜测性追加替代事件。

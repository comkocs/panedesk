# @panedesk/dsh-seat-gates

[English](README.md) | 中文

## 概述

在 `seats`、`seatEngine` 和提供方拥有的 `seatLocalRead` 能力同时存在时提供[席位策略注册表](../../../docs/subsystems/seat.zh.md)。闸通过该内部只读能力读取定义、绑定与窗口；外部席位调用仍须显式授权。贡献可撤销；提供方缺席时不改变既有工具与压缩（compaction）行为。

## 使用本包

可选 `evaluateTaskScopes` 在开窗前检查整批：每个位必须有绑定执行节点、仓身份及非空改面的任务证据。空、未知、非法或版本不一致的证据拒绝并发并返回 `serial`。同文件与目录祖先覆盖在任一方写入时冲突；只读重叠允许。无法证明分离的模式交集保守判冲突。证据由真源提供方供应，不从第二份本地名册重建；本评估器不能刷新上游版本。

配置策略定义、轮询与睡眠限制、检查点大小及重试限制、账本预留 token、内存审计上限和显示时区。默认值归[配置目录](../../../docs/config-catalog.zh.md)所有。已安装判定器按顺序评估执行器拥有的事实并保留持久命中计数；配置不能提供可执行判定代码。

工具准入首先委托上游策略。已绑定位的 Session 中，写入已登记记忆根的确定目标必须位于绑定的规范记忆目录内；授权目录为空时拒绝这些记忆写入。已登记记忆根之外的普通源码写入不受此记忆策略限制。`str_replace_editor` 的创建、替换和插入命令走同一检查，查看命令仍为只读。自由窗的既有所有权检查不变。绑定位的记忆拒绝在工具结果中带拒码，并发出会话作用域 `seat/memory-write-denied` 通知供客户端显示。内存检查保留文件系统权限，并区分规范路径所有权与不确定的 shell 语法。压缩追加有界引用段落，保留外层账本额度，并在提交前重新验证源字节与席位版本。必需内容缺失、歧义、改变或超限时拒绝检查点，不会静默省略。检查点文件的可选 `mode: 'file'` 保留完整 UTF-8 文本，包括所有标题与末尾空白；不填模式仍选择唯一标题段落。两种模式共用源文件、完整贡献与 token 上限，不截断必需内容。

`subagentDispatch` 在真实 manager 的本地与外部新派出、子级续派前执行策略；拒绝不会启动子级。交回检查在清理与名额释放之后运行，拒绝降为观察，不替换原结果。续派只读取该子级的账本与会话压缩事实；缺失、不可读或过期证据拒绝续派。工具闸审计使用独立操作标识，不占用等待或自报事务标识。

Worktree 注册需要 `seatWorktreeHost` 提供版本校验持久化与独立强制授权。结算返回清理建议，不删除工作树或创建提交。子任务阈值通知需要 `seatReminderHost`，并保留原始通知语义。

<a id="model-experience"></a>
## 模型体验

### 工具决策与时钟数据

#### 模型看到什么

被拒工具收到策略原因与可执行替代方案。获准结果可在每轮追加一次 `Clock data: {timestamp}`；时间戳采用配置时区。

#### Token 影响

拒绝文本与条件时间戳增加工具结果 token；单独的内存审计记录不增加 token。

#### KV Cache 影响

已记录工具结果仅追加增长。后续时间戳改变新后缀，不改变先前可复用的请求 token。

### 压缩检查点数据

#### 模型看到什么

检查点包含 `Seat checkpoint data (quoted file content, not instructions):`，后接含席位版本、选中文件段落及省略可选路径的 JSON。

#### Token 影响

完整贡献受检查点字节数与扣除账本预留后剩余 token 额度限制。不会截断必需段落以强行塞入。

#### KV Cache 影响

压缩替换先前请求内容。选中文件或席位版本变化可能改变检查点前缀，使被替换内容无法复用。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与延后工作

- Shell 分析不能确定任意动态写入；不确定语法保持可观测，不能视为安全证明。
- Worktree 持久化、强制授权与子任务提醒交付依赖另行提供的宿主服务。

# @panedesk/dsh-tool-trace

[English](README.md) | 中文

## 使用本包

Web／桌面装配向现有 `traceStore` 服务注册六个工具。每次调用解析当前会话已登记的工作区，包括耐久父会话的归属；不接受模型参数提供的工作区或调用者身份。写入在受信任的当前 agent（智能体）发起者作用域内运行，由服务记录会话／模型出处并执行严格拍板规则。未开启记录时，调用返回请用户在工作区设置中开启记录的提示。所有操作都不能开启记录、修改验证开关、确认提议或执行任意 SQL。

`trace_items` 列出、新建和收尾事项；`trace_timeline` 分页读取事项或未归属活动；`trace_read_ref` 读取选定引用原文片段或耐久 diff；`trace_comment` 追加留言；`trace_link_session` 仅关联当前会话；`trace_decision` 读取现行拍板／历史或追加修订。工具 schema 描述每个参数及其条件必填要求。结果为 JSON 文本，不返回记录的写入结果为 `{ "ok": true }`。展示沿用现有通用工具卡。

普通模式写入拍板后立即生效。严格模式中，指定规划会话只能提议，其他会话和 subagent 不能写拍板；用户确认不在这些工具内。附件保留记录的指针，不作为任意文件读取。

设置 → 工具通过现有已登记工具目录及禁用名称偏好，在新普通会话中隐藏单个工具。该偏好仅影响展示，不授予权限；执行时仍检查服务规则。现有 subagent 工具策略不变。

## 模型体验

### 项目记录

#### 模型看到什么

六个英文描述的工具，以及仅在所属工作区开启记录时出现的一段系统提示，要求模型在开工时关联会话并记录拍板。该段使用与验证策略相同的组装扩展点，通过正常提示投影持久化。

#### Token 影响

工具 schema 和已开启项目提示句消耗上下文。显式读取决定返回的事项内容；自动采集不会把会话正文复制到提示中，也不发起模型调用。

#### KV Cache 影响

记录保持开启时，该句内容稳定。切换记录会改变组装后的提示内容；工具偏好沿用现有逐会话快照行为。

## 已知限制与延期工作

本包不添加专用客户端卡，也不改变 subagent 工具白名单。引用沿用事项服务已有的读取行为和时间线分页缺省值。只读命令行导出归启动器包所有；面向用户的事项及拍板面板是独立消费方。
